# Instagram Postcard

Proyecto frontend de maquetación web inspirado en una tarjeta o publicación visual de Instagram, desarrollado con HTML y CSS.

## Tecnologías utilizadas

- HTML
- CSS
- Flexbox

## Objetivo del proyecto

Practicar la construcción de interfaces web simples, aplicando estructura semántica, maquetación con Flexbox y organización visual de componentes.

## Funcionalidades

- Estructura de tarjeta visual estilo Instagram
- Maquetación con Flexbox
- Uso de HTML semántico
- Estilos personalizados con CSS

## Lo que practiqué

- Organización de contenido en HTML
- Distribución de elementos con Flexbox
- Estilado visual con CSS
- Uso de Git para control de versiones
